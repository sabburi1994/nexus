# Contributing & Feedback to Nexus

Thank you for your interest in Nexus!

## Governance Model

Nexus is designed as an orchestrator-native AI agent framework built around strict architectural principles, typed monorepo contracts, and non-negotiable verification gates.

To preserve architectural integrity, security boundaries, and deterministic execution:

- **Nexus is maintained exclusively by the core author.**
- **External pull requests are disabled and will not be merged.** Any external pull requests will be automatically closed by our automation.

## How to Request Features or Report Issues

We warmly welcome community feedback, feature proposals, and bug reports:

1. **Feature Requests & Ideas**: Have an idea for a new agent role, a protocol connector, or a tool integration? Open a [Feature Request on GitHub Issues](https://github.com/sabburi1994/nexus/issues).
2. **Bug Reports**: Encountered unexpected behavior or schema validation errors? Please file a [Bug Report on GitHub Issues](https://github.com/sabburi1994/nexus/issues) with reproduction steps.
3. **Usage & Integration Questions**: Feel free to open an issue or reach out directly.

All improvements, features, and fixes will be reviewed, designed, and implemented directly by the author.
