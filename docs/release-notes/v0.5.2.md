## Highlights

### Real model generation & runtime fixes (`benchmarks/README.md`)
* **Accurate Gemini 3.8 Flash pricing (`nexus.ai.pricing`):** uses Vertex AI list prices by date
  (`0.75` / `3.75` USD per million until 2026-12-31, `1.50` / `7.50` from 2027-01-01), prices
  unknown models high so spend caps never undercount, and counts thinking tokens as output in
  `generate`, `converse`, and `structured`.
* **Token refresh & retries (`nexus.ai.client`):** reuses metadata tokens until 5 minutes before
  expiry, caches gcloud tokens for 5 minutes, refreshes and retries once on HTTP 401, and retries
  transport errors up to 3 times with backoff. Adds `invalidate_gcp_access_token()`.
* **End-to-end IT squad generation (`8/8` passing, `6/8` without healing):**
  * Full-stack prompt specifies exact module layout (`backend_models`, `nexus.db`),
    `app = create_nexus_app(...)` with a real SQLAlchemy session on `DATABASE_URL`, and UUID keys.
  * Code normalizer rewrites prompt field imports (`backend_models_py`) and misrouted Nexus imports
    (`from nexus.models import NexusEntity`).
  * `NexusEntity` uses SQLAlchemy's generic `Uuid` so generated apps work on both PostgreSQL and
    SQLite.
  * Healing prompt includes both backend files; QA sees all of `main.py`, the models, and extracted
    routes, runs startup via `with TestClient(app) as client`, and uses a fresh SQLite DB per run.

### MCP, local dashboard & showcase hardening
* **MCP server (`nexus mcp`):** defaults `serverInfo.version` to `nexus.__version__`, handles
  `ping`, stays silent on JSON-RPC notifications (such as `notifications/initialized`), and
  validates `params`/`arguments` objects (`-32600` / `-32602`).
* **Local dashboard (`nexus ui`):** built with `create_nexus_app` under strict CSP
  (`script-src 'self'; style-src 'self'`, `Cache-Control: no-store` on `/api/`), serves offline
  same-origin `/dashboard.css` and `/dashboard.js` (no external CDN, no inline scripts), and
  renders events via `textContent` instead of `innerHTML`.
* **Showcase backend:** aligned with [docs/ADOPTING.md](https://github.com/sabburi1994/nexus/blob/main/docs/ADOPTING.md)
  (`app = create_nexus_app(...)`, `mount_spa(...)`, `no_store_prefixes=("/api/",)`).
