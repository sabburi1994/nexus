**Latest stable release of Nexus.** Documentation and package metadata only: the code is the same as
[0.5.0](https://github.com/sabburi1994/nexus/releases/tag/v0.5.0), which has the actual changes.

```bash
pip install nexus-agent-framework==0.5.1
npm install @nexus-agent-framework/tokens @nexus-agent-framework/ui
```

## What is in this release

* A [changelog](https://github.com/sabburi1994/nexus/blob/main/CHANGELOG.md) for every package, linked
  from the PyPI and npm pages.
* The PyPI page and every npm page list the latest stable versions and link to these release notes.
* Docs only patch releases on npm so their pages pick that up: tokens 1.0.1, ui 1.0.2, contracts
  1.0.4, middleware 1.0.3, scraper 1.0.3. Their code is unchanged (`dist` of contracts, middleware
  and scraper is byte for byte the previous release).

## Highlights of the 0.5 line

* A monthly AI budget cap of `0` switches AI off (`ai_disabled`, 429); `None` means no cap; a negative
  cap fails at startup.
* Sync budget methods for worker threads (`ensure_within_budget_sync`, `record_sync`, `summary_sync`).
* The request id middleware is plain ASGI, so an app's own 413 body size limit survives it.
* `SecurityHeadersConfig(no_store_prefixes=...)` for `Cache-Control: no-store` on API paths.

Coming from 0.4.0: read [Upgrading from 0.4.0](https://github.com/sabburi1994/nexus/blob/main/docs/ADOPTING.md#upgrading-from-040).
