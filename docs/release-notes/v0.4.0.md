The backend adoption kit: shared, optional building blocks so the platform apps stop keeping their
own copies. First PyPI release since 0.1.1 (0.3.x was tagged only).

```bash
pip install nexus-agent-framework==0.4.0
pip install "nexus-agent-framework[oidc]==0.4.0"   # with the Google OIDC verifier
```

## New

* `nexus.api.ratelimit`: `SlidingWindowLimiter`, `client_ip` with trusted proxy hops, the
  `rate_limit` route dependency and `RateLimitMiddleware` with path rules (429 `rate_limited`).
* `nexus.api.spa`: `mount_spa` serves a Vite build safely (no path escapes, immutable hashed assets,
  `no-cache` HTML, JSON 404s under API prefixes).
* `nexus.ai.spend`: a persistent monthly AI spend ledger and `MonthlyBudget`, which fails closed when
  the ledger cannot be read (503 `ai_budget_unavailable`) and refuses calls past the cap (429
  `ai_budget_exhausted`).
* `nexus.api.oidc`: `GoogleOidcVerifier` and `require_google_oidc` for Cloud Scheduler and service
  account callers (extra `[oidc]`).
* `create_nexus_app(docs=False, health_path=..., ready_path=...)`; `HEAD` on health routes.
* [docs/ADOPTING.md](https://github.com/sabburi1994/nexus/blob/v0.4.0/docs/ADOPTING.md): moving an
  existing FastAPI app onto the kit.

## Also since 0.1.1 (0.3.x, tagged only)

* Generic 500 responses: exception text is logged, never returned (0.3.5).
* Model returned code is normalized before it is written; benchmarks (0.3.4).
* `nexus new` scaffold builds, starts and passes its own tests (0.3.3).
* `nexus dream` runs the generated tests for real; squad spend cap; fixed platform templates (0.3.2).
* `NexusSecurityHeadersMiddleware` and `SecurityHeadersConfig` (0.3.1).
* Closed CORS by default, platform Terraform modules (0.3.0).

Note: 0.5.0 changes the meaning of a budget cap of `0` (it now switches AI off).
