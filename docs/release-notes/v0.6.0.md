Pluggable HTTP model providers, buildable `@nexus-agent-framework/ui` 1.x generated frontends,
Alembic migrations + bearer auth starter scaffolds, and all `0.5.2` real-model / MCP / dashboard
hardening fixes.

```bash
pip install nexus-agent-framework==0.6.0
# with Google OIDC verification for Cloud Scheduler / service accounts:
pip install "nexus-agent-framework[oidc]==0.6.0"
```

## What's new in 0.6.0

* **Pluggable model providers (zero extra dependencies):**
  * `OpenAICompatibleProvider` (`OPENAI_API_KEY`, Ollama, vLLM, OpenRouter, LM Studio) and
    `AnthropicProvider` (`ANTHROPIC_API_KEY`) over `httpx`, both wired into `BudgetedProvider`
    spend caps, transport retries, and credential-redacted errors.
  * `create_provider()` factory (`vertex`, `gemini`, `openai`, `anthropic`, `claude`, `ollama`,
    `mock`) and CLI flags `nexus dream --provider --model --base-url`.
* **Complete Vite + React + TypeScript frontends on UI 1.x + Tokens 1.x:**
  * Generated apps emit `package.json` (`@nexus-agent-framework/tokens@^1.0.1`,
    `@nexus-agent-framework/ui@^1.0.2`, `@nexus-agent-framework/contracts@^1.0.4`), `index.html`
    (`data-nx-theme="base"`), `tsconfig.json`, `vite.config.ts`, `tailwind.config.js`,
    `postcss.config.js`, `src/main.tsx` (importing `tokens.css` and `styles.css`), and
    `src/index.css`.
  * `benchmarks/bench_generation.py` gains `--frontend` (`npm install`, `vite build`,
    `tsc --noEmit`) and `--infra` (Dockerfile, `deploy.sh`, Terraform checks).
* **Alembic migrations & HS256 bearer auth starter:**
  * `alembic.ini` + `migrations/env.py` (wired to `DATABASE_URL` and `nexus.db.Base.metadata`)
    generated for every `nexus dream` backend and via `nexus new <app> --with-migrations`.
  * Stdlib-only HS256 bearer token auth (`require_auth`, `CurrentUser`, `create_access_token`,
    `verify_access_token`) via `nexus new <app> --with-auth` and `nexus dream --with-auth`.
* **Unified local check runner:** `npm run check:all` (`scripts/check-all.mjs`) verifies Python
  (ruff, mypy, core & showcase pytest) and all 5 npm packages in one command.
* **Also included since 0.5.1 (previously staged as 0.5.2):**
  * Real-model Vertex AI benchmark **8/8 end to end** (`6/8` without healing): dated Gemini 3.8
    Flash list pricing, token expiry refresh + 401/transport retries, generic SQLAlchemy `Uuid`
    on `NexusEntity`, import normalizer rewrites, full-route QA with fresh DB per run.
  * MCP JSON-RPC compliance (`ping`, silent notifications, `__version__`), offline strict-CSP
    XSS-safe `nexus ui` dashboard, and showcase `mount_spa` + `no_store_prefixes` alignment.
